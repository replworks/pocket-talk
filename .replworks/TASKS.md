# TASKS.md — 온디바이스 타당성 스파이크

## 목표

"아이폰에서 소형 모델로 초중급 일상회화 말하기/듣기 연습이 되는가?"를 숫자와 직접 체험으로 판정한다.
제품 검증(사람이 돌아오는가)과는 별개다. 이 스파이크가 통과하기 전엔 온디바이스를 제품에 쌓지 않는다.

- 테스트 기기: iPhone 16, iOS 27.0.2 (Apple Intelligence 켜짐)
- 레벨: 초중급 일상회화
- 언어: 영어 (사용자는 한국인 억양)

## 역할 분담

- **[AGENT]** 터미널/시뮬레이터/유닛테스트로 스스로 실행하고 결과를 관찰할 수 있는 작업. 결과물은 파일로 남긴다.
- **[HUMAN]** 실기기, 실제 음성, 체감이 필요한 작업. 에이전트는 체크리스트와 기록 양식만 만든다.

규칙: 에이전트는 실제로 돌려보지 않은 절차나 결과를 쓰지 않는다. 실행 못 한 건 "미실행"으로 적는다.

## 통과 기준 (숫자는 시작값, 1번 결과 보고 조정)

| 항목      | 통과 기준                                                                                         |
| --------- | ------------------------------------------------------------------------------------------------- |
| 대화 품질 | 블라인드 평가에서 클라우드 모델 대비 "받아들일 만함" 비율 70% 이상, 문법 틀린 영어 출력 거의 없음 |
| 컨텍스트  | 30턴 이상 대화에서 주제/앞 내용을 놓치지 않음                                                     |
| 음성 인식 | 한국인 억양 샘플 단어 오류율이 대화 진행에 지장 없는 수준 (기준값은 3번에서 합의)                 |
| 지연      | 발화 종료 → AI 음성 시작 1.5초 이내, 이상적으론 1초 안팎                                          |
| 지속성    | 30분 연속 세션에서 발열로 중단/성능 저하 없음, 배터리 소모 허용 범위                              |

## 0. 샘플 앱 명세 (에이전트가 만들 것)

앱은 측정 도구다. 제품 UI가 아니다. 화면은 못생겨도 된다.

### 구조

- `Package/PocketTalkCore` (Swift Package): 순수 로직만. UI/프레임워크 의존 최소화.
  - `LanguageModelClient` 프로토콜: `respond(history:, userText:) async throws -> String`
  - `MockLanguageModelClient`: 테스트용 고정/스크립트 응답
  - `AppleOnDeviceClient`: FoundationModels 호출 구현 (iOS 타깃 전용, `#if canImport(FoundationModels)`)
  - `ContextManager`: 토큰 예산 안에서 오래된 턴을 요약으로 접고 최근 N턴 유지. 토큰 카운터는 주입(프로토콜)해서 테스트에선 가짜 카운터 사용
  - `WordErrorRate`: 단어 오류율 계산 (정규화: 소문자, 구두점 제거)
  - `ResultLogger`: 시나리오 결과/턴별 지연을 JSONL로 기록
- `App/PocketTalkSpike` (SwiftUI, 얇게): `project.yml`(XcodeGen)으로 프로젝트 생성. `.xcodeproj`를 손으로 편집하지 않는다.
- 화면 3개 (탭):
  1. **Scenario Runner**: `scenarios.json`(번들)을 읽어 선택한 클라이언트로 20개 시나리오 실행 → JSONL 저장, 진행 상태와 컨텍스트 사용량(토큰) 표시
  2. **ASR Test**: 문장 30개를 하나씩 보여주고 마이크로 인식(SpeechAnalyzer 계열) → 인식 결과와 정답을 나란히 표시, 문장별 WER을 CSV로 저장
  3. **Live Session**: 마이크 → 인식 → 모델 → 음성 합성의 한 턴 루프. 턴별 지연(발화 종료 → 첫 토큰 → 음성 시작)을 기록, 세션 시작/종료 시 배터리 %와 `ProcessInfo.thermalState` 기록
- 파일 내보내기: Info.plist에 `UIFileSharingEnabled`와 `LSSupportsOpeningDocumentsInPlace`를 켜서 파일 앱/AirDrop으로 Mac에 가져올 수 있게 한다.

## 메모

- iOS에서 온디바이스 컨텍스트는 입력과 출력이 같은 예산을 쓴다. 대화가 길면 요약 관리가 필수.
- 소형 모델은 사실을 지어내기 쉽다. 학습 앱에서는 틀린 영어를 자신 있게 말하는 게 가장 큰 리스크.
- Evaluations 프레임워크 사용 가능 여부는 별도로 확인 (2번/4번을 자동화할 수 있으면 교체).
