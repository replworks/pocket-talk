## 6. 방향 결정 (사용자, 2026-10-27)

- **서드파티 API는 쓰지 않는다.** 요청당 과금이 붙으면 이 스파이크의 목적(온디바이스/무과금 대화 연습)이 무너진다.
- 클라우드 하이브리드는 **애플이 제공하는 클라우드 모델**로만 검토한다. 유료일 가능성은 감수하되, 별도 API
  제공자 청구서가 생기는 구조는 배제한다.

### SDK에서 확인한 사실 (실행 아님, 시그니처 확인)

iOS 27 FoundationModels에 **`PrivateCloudComputeLanguageModel`** 이 이미 있다.

| 항목 | 확인한 내용 |
| --- | --- |
| 타입 | `final public class PrivateCloudComputeLanguageModel` (iOS 27.0+) |
| 모델 주입 | `LanguageModelSession(model: PrivateCloudComputeLanguageModel(), ...)` — 기존 클라이언트와 같은 세션 API |
| 가용성 | `.availability` / `.isAvailable`, 사유는 `deviceNotEligible`, `systemNotReady` |
| 과금/한도 | `.quotaUsage`, 오류에 `QuotaLimitReached`, `QuotaUsage.LimitIncreaseSuggestion` 존재 → **할당량 기반** |
| 근거 | `FoundationModels.swiftinterface` (시뮬레이터 SDK 27.1) |

→ 서드파티 없이 `AppleOnDeviceClient`와 같은 구조로 백엔드만 교체할 수 있다. 다만 가용성·할당량·요금은
기기/계정에서 **실제로 확인해야 한다**(아직 미실행).
